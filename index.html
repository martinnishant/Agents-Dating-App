Useful safeguards

Use adults only. Prefer explicit participation consent. No contact, face recognition, sensitive-trait inference, or claims that a compatibility score predicts real chemistry. Keep profile notes grounded in what people publicly chose to share.

People

Each person has two source links and a concise, editable profile.

Tip: CSV columns supported: name, role, city, linkedin, instagram, interests, wants, values, notes. Use a spreadsheet to build all 25 profiles quickly.

The agents meet

Structured first conversations on each participant’s behalf. Synthetic dialogue—nothing is sent.

What makes this different

Instead of matching on a single opaque number, agents compare stated interests, relationship intentions, everyday rhythms, and boundaries. The conversation makes the reasoning visible.

The agents are a playful decision-support demo, not actual autonomous people or a substitute for human consent.

Match rankings

Every person gets a ranked shortlist, with the reasons made inspectable.

How to read the score

Compatibility is a transparent heuristic, not a prediction. Each score balances shared interests (40%), aligned intentions (30%), overlapping values (20%), and practical context (10%).

80+ strong overlap60–79 promising<60 explore

Scores are symmetric in this demo. Real relationships are not a math problem: use the reasons and conversation, not the number alone.

Quick start

A simple, credible path to the demo

1. Collect 25 source pairs
For each adult participant, verify one LinkedIn and one public Instagram belong to the same person. For a real-person demonstration, seek opt-in; do not imply public posting equals consent to dating simulation.
2. Enter the minimum useful facts
Role / city; interests explicitly shared; stated dating intention; values or lifestyle only when public and relevant. Keep notes short and attach them to source context. Don't guess private preferences.
3. Import in bulk
People → Export CSV to get a template, fill it in a spreadsheet, then Import CSV. Or add profiles one by one. All data stays in local browser storage.
4. Run the match model
Agent dates creates readable conversations and a ranked list for each profile. Open a person to inspect their analysis and their own best matches.
5. Shoot your video
Screen-record the live site: start at a profile analysis, run/show a conversation, open rankings; close with how the site works. Keep the video under 3 minutes and show only people whose use you are authorized to demonstrate.

Limits & implementation

This is a static single-page application (HTML, CSS, vanilla JavaScript, browser localStorage). It does not scrape Instagram or LinkedIn, bypass login, call an LLM, or send messages. Source review and profile entry are manual; compatibility and agent dialogue are local, explainable simulations. That is deliberately transparent and avoids inventing a scraping stack or requiring paid API access.
